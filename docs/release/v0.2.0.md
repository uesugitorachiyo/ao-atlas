# AO Atlas v0.2.0

Supported targets:

- Linux x86_64
- macOS aarch64
- Windows x86_64

Each supported archive receives a provider-free installation smoke check. Checksums, an SBOM, and provenance evidence are available with each candidate.

No signing key is configured for this rehearsal, so signature verification is reported as not applicable. Linux aarch64 is not supported or released in v0.2.0.
